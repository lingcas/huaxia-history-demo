# Huaxia PUA Serif

`Huaxia PUA Serif Medium` is a modified, single-glyph subset of Noto Serif HK.
It exists only to give approved legacy Private Use Area code points a stable
cross-platform outline in the reading interface.

- Original font: Noto Serif HK
- Original font version: `2.02;241114204554;non-release`
- Original font SHA-256: `6d0dd4f2306d48a82b0767e4e45a4a90ab3b62f3788422683b2ec44619d8db06`
- Original font copyright notice: Copyright © 2017-2023 Adobe
- Modified font family: Huaxia PUA Serif
- License: SIL Open Font License 1.1 (see `OFL.txt`)
- Build tool: FontTools 4.63.0

The family was renamed because this is a Modified Version. The subset retains
the approved U+24521 outline and maps the source code point U+EBBC to the same
outline. The timeline's `sourceText` continues to contain U+EBBC; no source
character is rewritten by the font build.

- Noto Serif CJK license: https://github.com/notofonts/noto-cjk/blob/main/Serif/LICENSE
- HKSCS-2004 mapping standard: https://www.ccli.gov.hk/doc/e_hkscs_2004.pdf
